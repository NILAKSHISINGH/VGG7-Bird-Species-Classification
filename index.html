ABOUT THE MODEL

Built with VGG7

A custom convolutional neural network built with PyTorch for 20-class bird species classification.

VGG7 CNN

Custom convolutional architecture with four convolutional blocks followed by fully connected classification layers.

⚡

PyTorch

The model was implemented and trained using PyTorch and torchvision.

20 Classes

The classifier recognizes 20 different bird species from the training dataset.
